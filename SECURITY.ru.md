# Политика безопасности

[English](SECURITY.md)

Не публикуйте эксплуатируемые уязвимости в обычных issues. Отправьте private GitHub Security Advisory maintainers репозитория: версия, шаги воспроизведения, влияние и возможное исправление. Не прикладывайте реальные credentials и лишние персональные данные.

Security fixes ориентированы на актуальную development-версию. ApexHUD — early beta, формального SLA пока нет, но отчёты будут рассмотрены максимально быстро.

Community-модули поддерживаются независимо. Сообщите автору модуля и maintainers ApexHUD, если требуется предупреждение или удаление из каталога.
