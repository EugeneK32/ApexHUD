# Правила поведения

[English](CODE_OF_CONDUCT.md)

Участники ApexHUD должны общаться уважительно, критиковать работу, а не человека, доброжелательно относиться к вопросам и не допускать травли, дискриминации, угроз, сексуализированного поведения, публикации чужих данных и намеренного срыва обсуждений. Maintainers могут редактировать или удалять оскорбительный контент и ограничивать участие. О проблемах сообщайте privately maintainers репозитория или через GitHub Security Advisory, если требуется конфиденциальность.
