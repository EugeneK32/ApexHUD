# Security Policy

[Russian version](SECURITY.ru.md)

Please do not disclose exploitable vulnerabilities in public issues. Send a private GitHub Security Advisory to the repository maintainers with affected version, reproduction steps, impact, and suggested mitigation. Do not include real credentials or unrelated personal data.

Supported security fixes target the latest development version. ApexHUD is early beta; no formal response SLA is promised, but reports will be acknowledged and triaged as promptly as possible.

Community modules are independently maintained. Report a catalog module vulnerability to its author and notify ApexHUD maintainers when catalog removal or warning is appropriate.
