# Модель радара

[English](../en/radar.md)

Radar ApexHUD — улучшенная визуализация spotter, а не сканер мировых координат. Авторитетное состояние стороны берётся из iRacing `CarLeftRight`. Lap-distance arrays помогают связать машину и приблизительно оценить продольную дистанцию.

`overlap` в protocol v6 — нормализованная оценка глубины нахождения бок о бок `0..1`. Это не физическое пересечение и не расстояние в метрах. В пользовательских настройках лучше использовать понятные nearby/warning/critical distance.

Если iRacing сообщает машину сбоку, но candidate нельзя уверенно сопоставить, создаётся synthetic contact. Модуль должен принимать отрицательный `carIndex`, неизвестные side/threat и несколько машин с одной стороны.

Встроенный radar рисуется непосредственно overlay-host, а не iframe, чтобы гарантировать прозрачность. В гонке видны только markers; selection outline принадлежит visual editor.
