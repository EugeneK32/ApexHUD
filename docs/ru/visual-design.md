# Визуальная система для гонки

[English](../en/visual-design.md)

Гоночный HUD нельзя рассматривать как dashboard, в который водитель всматривается. Он должен передавать состояние коротким периферийным взглядом.

- Один главный показатель на виджет.
- Стабильная геометрия без прыгающих строк.
- Цвет используется по смыслу, а не как украшение.
- Крупные tabular numerals и короткие подписи.
- Без лишних glow, blur, слоёв прозрачности и бессмысленной анимации.
- Критичное предупреждение может пульсировать; обычное значение не должно мерцать.
- Shift guidance не должен мигать раньше штатного порога. Protocol v6 отдаёт `shiftIndicatorPercent`, `shiftPowerPercent`, RPM thresholds и `revLimiterActive`.
- Голубая подсказка downshift остаётся эвристикой и визуально не должна выглядеть как команда симулятора.
- Тестируйте реальный размер поверх движущейся трассы, а не только увеличенное preview.
- Opacity, scale, units и compact modes нужны только при реальной пользе.

Таблицы обязаны показывать игрока и ближайшую борьбу вне top N. В мультиклассе class и overall position подписываются однозначно. Графики должны обрезаться внутри bounds.
