# Code of Conduct

[Russian version](CODE_OF_CONDUCT.ru.md)

ApexHUD contributors are expected to communicate respectfully, criticize work rather than people, welcome good-faith questions, and avoid harassment, discrimination, threats, sexualized conduct, doxxing, or deliberate disruption. Maintainers may edit, hide, or remove abusive content and restrict participation when necessary. Report conduct problems privately through repository maintainer contact or a GitHub Security Advisory when privacy is required.
