# Шаблон модуля ApexHUD

[English](README.md)

Скопируйте папку, задайте уникальный reverse-DNS `manifest.id`, запросите только нужные scopes protocol v6 и храните runtime assets внутри модуля. Выполните `npm run verify` из корня и проверьте виджет в mock и live telemetry в реальном гоночном размере.

См. `docs/ru/module-development.md`.
