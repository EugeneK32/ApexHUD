# Changelog

## 4.0.1

- Fixed the standings renderer not starting inside ApexHUD sandboxed iframes.
- Replaced ES-module loading with CSP-compatible classic scripts.
- Restored visual-editor demo rows and live iRacing standings updates.

## 4.0.0

- Complete visual redesign.
- Added deterministic test data in visual edit mode.
- Added 41 fine-grained display and appearance settings.
- Added grouped multiclass mode and corrected per-class row allocation.
- Added leaders, player-window and hybrid driver selection modes.
- Added gap and timing column modes.
- Added session header variants, density variants and class-header styles.
- Added position-change tracking from the first observed position in a session.
- Added configurable class palettes and foreground contrast handling.
- Added compatibility migration for selected 3.x settings.
- Changed author metadata to Eugene Konovalov.
## 5.1.0

- Reworked the module around compact real-race placement.
- Reduced minimum bounds and default footprint.
- Added responsive degradation for very small sizes.
