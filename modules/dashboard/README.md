# Race Dashboard

A protocol v6 speed, gear and shift display for ApexHUD. Uses the simulator shift indicator when available, with car RPM thresholds as fallback. Includes ABS, TC, pit-limiter and brake-bias context.

**Author:** Eugene Konovalov  
**Scopes:** `vehicle`, `driverAids`  
**Requires:** ApexHUD telemetry protocol v6
