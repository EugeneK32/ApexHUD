# Proximity Radar

A protocol v6 top-down radar fallback with side contacts, fast-approach contacts and stable editor demo data.

> ApexHUD may render `com.apexhud.radar` through its native radar renderer. In that build, host-side radar code remains authoritative while this package supplies the manifest, settings and iframe fallback.

**Author:** Eugene Konovalov  
**Scope:** `radar`  
**Requires:** ApexHUD telemetry protocol v6
